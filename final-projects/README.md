# 最终项目方向

- **Networked Tool**：网络状态灯、Wi-Fi 诊断工具、物理通知按钮
- **IoT Device**：环境监视器、Web/MQTT dashboard
- **Smart Utility**：智能计时器、信息显示、电脑物理接口
- **Embedded System**：串口桥、通信监视器、可升级设备
- **可选 Control**：控制/机器人接口扩展，不作为课程前提

项目报告顺序：需求与约束 → 系统图与模块 → 协议选择 → 状态/任务设计 → 实现 → 自动测试 → 故障与 Debug → 硬件清单 → 文档 → 部署/OTA。
